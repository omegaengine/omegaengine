# AlphaFramework.Presentation

AlphaFramework is a Model-View-Presenter framework for creating game worlds with [OmegaEngine](https://www.nuget.org/packages/OmegaEngine).

**AlphaFramework.Presentation** provides a basis for building presenters that visualize [AlphaFramework.World](https://www.nuget.org/packages/AlphaFramework.World)-based game worlds using OmegaEngine graphics.

[Documentation](https://docs.omegaengine.de/)

## Related packages

- [OmegaEngine](https://www.nuget.org/packages/OmegaEngine) provides 3D graphics rendering based on DirectX 9.
- [AlphaFramework.World](https://www.nuget.org/packages/AlphaFramework.World) provides a basis for engine-agnostic models of game worlds.
- [AlphaEditor](https://www.nuget.org/packages/AlphaEditor) is a toolkit for creating editors for games based on AlphaFramework.
