# OmegaGUI

**OmegaGUI** is a GUI toolkit for [OmegaEngine](https://www.nuget.org/packages/OmegaEngine). It has an XML file format for describing UIs ([AlphaEditor](https://www.nuget.org/packages/AlphaEditor) provides a WYSIWYG editor) and uses Lua scripting for event handling.

[Documentation](https://docs.omegaengine.de/)

## Related packages

- [OmegaEngine](https://www.nuget.org/packages/OmegaEngine) provides 3D graphics rendering based on DirectX 9.
- [AlphaEditor](https://www.nuget.org/packages/AlphaEditor) is a toolkit for creating editors for games based on AlphaFramework, including a WYSIWYG editor for OmegaGUI dialogs.
