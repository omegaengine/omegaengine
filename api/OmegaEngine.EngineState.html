Color

Remarks

Linearized on upload: fixed-function fog is applied before the sRGB conversion in the ROP (even for pixel-shader draws), so an un-linearized color would come out too bright. Must stay consistent with the background color, which is cleared with SrgbWrite turned off and therefore lands in the render target already encoded.

SrgbWrite

Shall pixels be gamma-encoded (linear to sRGB) when written to the render target?

public bool SrgbWrite { get; set; }

Property Value

bool

Remarks

Turned on for the scene pass, where all shading arithmetic happens in linear space, and off everywhere else (post-screen shaders, GUI, fades, depth targets), which operate on already-encoded values. Whether Device.Clear is affected by this is hardware-dependent, so turn it off around clears of already-encoded colors rather than relying on either behavior.

See Also
